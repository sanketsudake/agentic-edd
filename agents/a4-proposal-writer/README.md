# A4 proposal-writer

Writes the five-section client proposal from the scope, the priced lines, and the five figures. Copies every number.
Must not change a number, add scope, or promise a date.

- Input: `{{inputs}}` = client, scope, lines, figures, reviewer findings
- Output: `schemas/a4-proposal.json`
- Final prompt: `prompts/v2.md`, 14/14. Two rounds.
- Test inputs are generated by `node tests/make-inputs.js`, so every figure equals what the pipeline computes.
- Run: `npm run eval -- a4-proposal-writer v2`
