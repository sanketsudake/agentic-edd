# A4 `proposal-writer`

Role: executive bid manager (source document, Agent 4).
Responsibility: render the five-section client proposal in markdown from the scope, the priced lines, and the computed financials. Copy every figure; write three exclusions that fit the project type; state 30-day validity and a signature line. Apply the reviewer's findings on a revise loop.
Must not: change a number, add scope, or promise a date the RFP did not ask for.

Input: `{{inputs}}` — JSON with `client`, `scope`, `lines`, `financials`, `findings`.
Output: JSON that matches `schemas/a4-proposal.json`.

Evaluation evidence: `prompts/v*.md`, `promptfooconfig.yaml`, `eval-script.js`, `ITERATION_LOG.md`, `results-v*.html`.
`tests/inputs/*.json` are generated by `node tests/make-inputs.js` from the A2 BOM fixtures and `harness/financials.js`.

```bash
node tests/make-inputs.js
npm run eval -- a4-proposal-writer v1
```
