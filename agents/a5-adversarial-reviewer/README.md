# A5 adversarial-reviewer

Attacks the proposal: wrong numbers, invented scope, unfit exclusions, promises, missing sections, unprofessional tone. Returns a verdict.
Must not rewrite the proposal.

- Input: `{{inputs}}` = proposal, scope, lines, figures, RFP
- Output: `schemas/a5-review.json`
- Final prompt: `prompts/v4.md`, 17/18 (Kimi K3 9/9, SWE-1.6 8/9). Four rounds. The pipeline uses Kimi K3.
- Test inputs are one clean proposal and eight planted defects, generated by `node tests/make-inputs.js`.
- Run: `npm run eval -- a5-adversarial-reviewer v4`
